# JD Amulet Switcher

Макро-переключатель амулетов для Jade Dynasty (клиент 3.1.1, оконный режим).
Нажимаете клавишу скилла — программа сама жмёт клавишу амулета, выдерживает паузу N мс и жмёт скилл.
Работает только через эмуляцию клавиатуры: без чтения памяти, инъекций, захвата экрана и кликов мышью.

## Сборка

Нужен .NET 8 SDK.

```bat
:: лёгкий exe (~0.4 МБ), на ПК нужен .NET 8 Desktop Runtime
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false

:: exe без зависимостей (~70 МБ)
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true
```

Результат: `bin\Release\net8.0-windows\win-x64\publish\JdAmuletSwitcher.exe`.
Конфиг `JdAmuletSwitcher.json` создаётся рядом с exe.

## Структура

| Слой | Файл | Назначение |
|---|---|---|
| Native | `Native/NativeMethods.cs` | P/Invoke, структуры INPUT/KBDLLHOOKSTRUCT |
| KeyboardHook | `Input/KeyboardHook.cs` | WH_KEYBOARD_LL на своём потоке с циклом сообщений |
| InputSender | `Input/InputSender.cs` | выделенный поток ввода, SendInput (скан-коды) / PostMessage |
| PrecisionDelay | `Input/PrecisionDelay.cs` | высокоточный waitable-таймер + spin на последние 1–2 мс |
| GameWindowTracker | `Game/GameWindowTracker.cs` | поиск окна игры и слежение за ним через WinEvents |
| MacroEngine | `Engine/MacroEngine.cs` | логика хука, связки, состояние надетого амулета, лог |
| Config | `Config/AppConfig.cs` | профили, JSON |
| UI | `UI/MainForm.cs`, `UI/OverlayBar.cs`, … | окно настроек, трей, оверлей-бар |

## Быстрый старт

1. Запустите exe (попросит права администратора — как и клиент игры).
2. В таблице «Связки» выберите связку → «Изменить»: клавиша скилла (например F3), клавиша амулета (например 7),
   задержка, комбинация для бара. Нажмите на поле и затем нужную клавишу. Backspace — очистить.
3. Переключитесь в игру: над клиентской областью появится бар. Нажимайте скилл как обычно.

## Подбор задержки

1. Поставьте задержку 0 мс (ползунок под таблицей меняет её сразу, без перезапуска).
2. Нажимайте скилл и проверяйте, срабатывает ли бонус амулета.
3. Если бонус срабатывает не всегда, прибавляйте по 10 мс, пока он не начнёт срабатывать стабильно.
   Затем можно убавлять по 2–5 мс, чтобы найти минимум.
4. В логе для каждого нажатия видно фактическую паузу и время от перехвата клавиши до отправки скилла.

## Если игра не реагирует

* Программа должна быть запущена от администратора (это требует манифест). Ошибка с кодом 5 в логе — блокировка UIPI.
* Поменяйте «Режим ввода» на **PostMessage в окно игры** и повторите тест.
* Проверьте имя процесса (по умолчанию `ElementClient.exe`) и строку «Игра: …» в статусе.
* Если амулет «не переключается», потому что программа считает его уже надетым, нажмите «Сбросить состояние амулета»
  или включите «Всегда надевать амулет».

## Клавиши

* **Pause** — включить или выключить макросы (работает глобально, клавишу можно сменить).
* **Ctrl+1…Ctrl+5** — связки бара (настраиваются). Основной амулет — своя комбинация.
* При зажатых Ctrl/Alt/Shift связка по клавише скилла не срабатывает: такие нажатия уходят в игру без изменений.
